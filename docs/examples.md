# Usage examples

Each section below is a request that you can type to an AI assistant that has this server connected: the prompt, the tool calls that the assistant makes for it, what the server returns, and what the assistant can tell you from that. [The README](../README.md) shows how to connect a client.

> **All values on this page are synthetic.** The results come from running the real server against the fake TradingView app of the test suite, which serves a made-up NASDAQ:AAPL chart: prices from a seeded random walk, one bar for every calendar day (weekends included), an invented layout, invented scripts and an invented strategy report. Indicator values follow the closing prices instead of being calculated by the indicators. Nothing here is market data, and nothing comes from a real account. The shape of every result, with its field names, error codes and hints, is what the server returns for real.

Every result is the envelope of the server: `ok`, then `data` or `error`, then `meta`. `meta.durationMs` is left out, because it differs on every run, and a list longer than three items is cut to its first three followed by a marker such as `"… 1 more"`. Text with line breaks, such as a script or a diff, is laid out again as lines below its block. The time of a compilation is fixed as well, because the fake app takes it from the clock.

This page is generated by `pnpm docs:examples` from the scenarios in `packages/server/scripts/docs/scenarios.ts`, and a test fails when it is out of date. Do not edit it by hand.

## 5. Add an indicator to a full chart

**You type**

> Add the MACD to my chart.

**The assistant calls `indicator_search`**

```json
{ "query": "macd" }
```

**The server returns**

```json
{
  "ok": true,
  "data": {
    "results": [
      {
        "name": "Moving Average Convergence Divergence",
        "shortName": "MACD",
        "id": "STD;MACD",
        "kind": "pine",
        "isStrategy": false
      }
    ]
  },
  "meta": { "via": "internal", "warnings": [] }
}
```

**Then it calls `indicator_add`**

```json
{ "name": "STD;MACD" }
```

**The server returns an error**

```json
{
  "ok": false,
  "error": {
    "code": "PLAN_LIMIT",
    "message": "The chart holds as many indicators as the plan allows (2)",
    "hint": "Remove an indicator first: indicator_list gives their ids, and indicator_remove removes one (an indicator this session did not add needs confirm: true).",
    "details": { "feature": "INDICATORS_ON_CHART", "limit": 2 }
  }
}
```

**The assistant answers**

> TradingView has the Moving Average Convergence Divergence (MACD, id STD;MACD), but it was not added: the chart already holds as many indicators as the plan allows, 2 (the error is PLAN_LIMIT, for INDICATORS_ON_CHART). To make room, one of the two indicators would have to go. indicator_remove can remove it, but it needs confirm: true for an indicator that this session did not add, so the assistant asks you before it does.

## 6. Write and compile a Pine script

## 7. Fix a Pine script with smart compile

**You type**

> The script in my Pine Editor will not compile. Can you fix it?

**The assistant calls `pine_smart_compile`**

```json
{}
```

**The server returns**

```json
{
  "ok": true,
  "data": {
    "success": true,
    "attempts": [
      {
        "errors": [
          {
            "line": 2,
            "column": 1,
            "endLine": 2,
            "endColumn": 5,
            "message": "Could not find function or function reference 'study'",
            "severity": "error"
          }
        ],
        "applied": ["Replace study( with indicator(", "Replace rsi( with ta.rsi("]
      },
      { "errors": [], "applied": [] }
    ],
    "source": "//@version=6\nindicator(\"RSI line\")\nplot(ta.rsi(close, 14))\n",
    "diff": "@@ -1,3 +1,3 @@\n //@version=6\n-study(\"RSI line\")\n-plot(rsi(close, 14))\n+indicator(\"RSI line\")\n+plot(ta.rsi(close, 14))\n",
    "writtenBack": false
  },
  "meta": { "via": "internal", "warnings": [] }
}
```

`source`:

```pine
//@version=6
indicator("RSI line")
plot(ta.rsi(close, 14))
```

`diff`:

```diff
@@ -1,3 +1,3 @@
 //@version=6
-study("RSI line")
-plot(rsi(close, 14))
+indicator("RSI line")
+plot(ta.rsi(close, 14))
```

**The assistant answers**

> The first attempt failed at line 2, column 1: the compiler could not find the function study, a name of Pine v4 in a script that says //@version=6, and stopped there. The rules know every such name, so two fixes were applied, study( became indicator( and rsi( became ta.rsi(, and the second attempt compiled (success is true). The diff shows what changed. The Pine Editor still holds your original text (writtenBack is false), and the assistant can write the fixed text into it if you want it there.
