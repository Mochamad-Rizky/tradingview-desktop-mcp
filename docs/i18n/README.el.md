Ένας server [MCP](https://modelcontextprotocol.io) που επιτρέπει σε βοηθούς τεχνητής νοημοσύνης να
διαβάζουν και να ελέγχουν την εφαρμογή TradingView Desktop στον δικό σας υπολογιστή. Χειρίζεται την
εφαρμογή στην οποία είστε ήδη συνδεδεμένοι μέσω του Chrome DevTools Protocol, από τη θύρα αποσφαλμάτωσης
που ανοίγει η εφαρμογή όταν ξεκινά με `--remote-debugging-port`. Αυτοματοποιεί μόνο την τοπική
εφαρμογή: δεν συνδέεται για λογαριασμό σας, δεν παρακάμπτει τα όρια του πλάνου σας και δεν καλεί τους
servers του TradingView.

> **Κατάσταση: πριν από την 1.0.** Τα ονόματα και οι επιλογές των εργαλείων μπορεί να αλλάξουν πριν
> από την 1.0. Εγκαταστήστε το πακέτο από το npm, όπως παρακάτω, ή εκτελέστε τον server
> [από τον πηγαίο κώδικα](#quick-start-from-source). Έχει δοκιμαστεί σε macOS· σε Windows και Linux
> η υποστήριξη είναι στο μέτρο του δυνατού.

Ο server προσφέρει εργαλεία εφαρμογής (εκκίνηση, κατάσταση υγείας, εντοπισμός, κατάσταση διεπαφής,
όρια πλάνου, επανασύνδεση), εργαλεία γραφήματος (κατάσταση, σύμβολο, χρονικό διάστημα, τύπος
γραφήματος, ορατό εύρος, κύλιση), εργαλεία δεδομένων αγοράς (μπάρες, τιμές, πληροφορίες και
αναζήτηση συμβόλων), εργαλεία δεικτών (λίστα, αναζήτηση, προσθήκη, αφαίρεση, παράμετροι, ορατότητα,
τιμές), εργαλεία Pine Script (ο editor και τα αποθηκευμένα scripts, μεταγλώττιση, έξυπνη
μεταγλώττιση με διορθώσεις βάσει κανόνων, ανάλυση εκτός σύνδεσης, η κονσόλα, καθώς και οι γραμμές,
οι ετικέτες, τα πλαίσια και οι πίνακες που σχεδιάζουν τα scripts), εργαλεία Strategy Tester
(αποτελέσματα, συναλλαγές, καμπύλη κεφαλαίου), εργαλεία σχεδίων, ειδοποιήσεων και λιστών
παρακολούθησης, εργαλεία διατάξεων, πολλαπλών γραφημάτων και καρτελών, bar replay, στιγμιότυπα
οθόνης, εργαλεία διεπαφής χαμηλού επιπέδου (κλικ, hover, πληκτρολόγηση, πλήκτρα, κύλιση, εύρεση,
πάνελ, πλήρης οθόνη, και JavaScript στη σελίδα του γραφήματος όταν το επιτρέψετε) και το
`batch_run`, που εκτελεί πολλά εργαλεία σε μία κλήση. Προσφέρει επίσης πόρους (την κατάσταση υγείας
της εφαρμογής, την κατάσταση και τις μπάρες του γραφήματος, τον κώδικα Pine και το τελευταίο
αποτέλεσμα μεταγλώττισης, την αναφορά της στρατηγικής, την ενεργή λίστα παρακολούθησης), ο καθένας
μαζί με το εργαλείο με το οποίο μοιράζεται τα δεδομένα του, και πέντε prompts για συνηθισμένες
εργασίες. Ένα web dashboard δείχνει τις κλήσεις ζωντανά και εκτελεί εργαλεία χειροκίνητα (δείτε
[Dashboard](#dashboard)).

## <a id="install-by-asking-your-ai-app"></a>Εγκατάσταση ζητώντας το από την εφαρμογή AI σας

Δεν χρειάζεται να πληκτρολογήσετε καμία εντολή μόνοι σας. Αν η εφαρμογή AI σας μπορεί να εκτελεί
εντολές στον υπολογιστή σας, όπως το Claude Code, το Cursor, το VS Code, το Windsurf, το Gemini CLI
και το Codex CLI, μπορεί να κάνει τη ρύθμιση για εσάς. Πρώτα:

1. Εγκαταστήστε το [TradingView Desktop](https://www.tradingview.com/desktop/) και συνδεθείτε.
2. Εγκαταστήστε το [Node.js](https://nodejs.org) (την έκδοση LTS), αν δεν το έχετε ήδη.

Έπειτα αντιγράψτε αυτό το prompt, επικολλήστε το στην εφαρμογή AI σας και στείλτε το:

```text
Εγκατάστησέ μου τον TradingView MCP server. Είναι το πακέτο npm tradingview-desktop-mcp
(https://github.com/Mochamad-Rizky/tradingview-desktop-mcp). Ακολούθησε αυτά τα βήματα και εξήγησέ μου
το καθένα με απλά λόγια, στα ελληνικά:

1. Έλεγξε ότι είναι εγκατεστημένο το Node.js 20.19 ή νεότερο. Αν δεν είναι, σταμάτα και πες μου πώς
   να το εγκαταστήσω.
2. Εκτέλεσε "npx -y tradingview-desktop-mcp config <client>", όπου <client> είναι η εφαρμογή μέσα
   στην οποία τρέχεις (claude-code, cursor, vscode, windsurf, gemini-cli ή codex-cli). Κάνε ό,τι
   τυπώνει για να προσθέσεις τον server στη ρύθμισή μου, και κράτησε όποιους άλλους servers υπάρχουν
   ήδη εκεί.
3. Ξεκίνησε το TradingView με "npx -y tradingview-desktop-mcp launch". Αν πει ότι το TradingView
   τρέχει ήδη χωρίς τη θύρα αποσφαλμάτωσης, ρώτα με πρώτα, και μόνο αν συμφωνήσω εκτέλεσέ το ξανά
   με --restart, γιατί αυτό κλείνει το TradingView και μπορεί να χάσω μη αποθηκευμένες αλλαγές.
4. Εκτέλεσε "npx -y tradingview-desktop-mcp doctor" και πες μου αν περνούν όλοι οι έλεγχοι. Αν
   αποτύχει ο έλεγχος του γραφήματος, πες μου να φέρω την καρτέλα του γραφήματος μπροστά στο
   TradingView.
5. Πες μου αν πρέπει να σε επανεκκινήσω ή να ανοίξω νέα συνομιλία για να εμφανιστούν τα εργαλεία
   του TradingView.
```

Όταν τελειώσει, επανεκκινήστε την εφαρμογή ή ανοίξτε νέα συνομιλία αν σας το ζήτησε, και ρωτήστε
«Έλεγξε ότι το TradingView είναι συνδεδεμένο.» Έπειτα δοκιμάστε τα [prompts παρακάτω](#try-these-prompts).

Χρησιμοποιείτε το Claude Desktop; Δεν μπορεί να εκτελεί εντολές, αλλά το Claude Code, το Cursor και
οι άλλες εφαρμογές παραπάνω μπορούν να το ρυθμίσουν για εσάς: προσθέστε «Ρύθμισέ το για το Claude
Desktop (config claude-desktop), όχι για αυτή την εφαρμογή.» στο τέλος του prompt. Το ChatGPT και το
OpenAI API χρειάζονται ένα tunnel, το οποίο στήνετε χειροκίνητα (δείτε
[Απομακρυσμένοι clients και tunnels](#remote-clients-and-tunnels)). Αν ο βοηθός κολλήσει,
ακολουθήστε μόνοι σας τα παρακάτω βήματα.

## <a id="install"></a>Εγκατάσταση

Χρειάζεστε:

- Το TradingView Desktop, εγκατεστημένο και με σύνδεση στον λογαριασμό σας.
- Το Node.js 20.19 ή νεότερο, που παρέχει το `npx`.

Δεν εγκαθίσταται τίποτε άλλο: οι clients παρακάτω ξεκινούν τον server με
`npx -y tradingview-desktop-mcp`, που κατεβάζει το πακέτο στην πρώτη χρήση. Ξεκινήστε το TradingView
με τη θύρα αποσφαλμάτωσης. Η εντολή `launch` βρίσκει την εφαρμογή και την ξεκινά με αυτόν τον τρόπο:

```sh
npx -y tradingview-desktop-mcp launch
```

Το TradingView επιτρέπει μόνο ένα στιγμιότυπο. Αν τρέχει ήδη χωρίς τη θύρα αποσφαλμάτωσης, το
`launch` σταματά και το αναφέρει· το `launch --restart` το κλείνει ομαλά και το ξεκινά ξανά με τη
θύρα, και το TradingView μπορεί πρώτα να σας ζητήσει να αποθηκεύσετε αλλαγές. Ελέγξτε ότι ο server
μπορεί να φτάσει την εφαρμογή:

```sh
npx -y tradingview-desktop-mcp doctor
```

Το `doctor` αποτυγχάνει στον έλεγχο του γραφήματος όσο η καρτέλα του γραφήματος βρίσκεται στο
παρασκήνιο, πίσω από τη σελίδα νέας καρτέλας ή από άλλη καρτέλα χωρίς γράφημα, οπότε φέρτε την
καρτέλα του γραφήματος μπροστά.
Το `npx -y tradingview-desktop-mcp --help` απαριθμεί τις επιλογές, και το [.env.example](../../.env.example)
τις μεταβλητές περιβάλλοντος.

## <a id="connect-your-ai-app"></a>Σύνδεση της εφαρμογής AI σας

Το `config <client>` τυπώνει το απόσπασμα ρύθμισης ενός client και λέει πού πρέπει να μπει. Κάθε
οδηγός παρακάτω περιέχει το ίδιο απόσπασμα, τα βήματα για τη συγκεκριμένη εφαρμογή και τι να κάνετε
όταν κάτι δεν λειτουργεί.

| Client                                         | Εκτύπωση του αποσπάσματος                              |
| ---------------------------------------------- | ------------------------------------------------------ |
| [Claude Desktop](../clients/claude-desktop.md) | `npx -y tradingview-desktop-mcp config claude-desktop` |
| [Claude Code](../clients/claude-code.md)       | `npx -y tradingview-desktop-mcp config claude-code`    |
| [Cursor](../clients/cursor.md)                 | `npx -y tradingview-desktop-mcp config cursor`         |
| [VS Code](../clients/vscode.md)                | `npx -y tradingview-desktop-mcp config vscode`         |
| [Windsurf](../clients/windsurf.md)             | `npx -y tradingview-desktop-mcp config windsurf`       |
| [Gemini CLI](../clients/gemini-cli.md)         | `npx -y tradingview-desktop-mcp config gemini-cli`     |
| [Codex CLI](../clients/codex-cli.md)           | `npx -y tradingview-desktop-mcp config codex-cli`      |
| [ChatGPT](../clients/chatgpt.md)               | `npx -y tradingview-desktop-mcp config chatgpt`        |
| [OpenAI API](../clients/openai-api.md)         | `npx -y tradingview-desktop-mcp config openai-api`     |

Το προεπιλεγμένο transport είναι το stdio, όπου το stdout μεταφέρει μόνο μηνύματα MCP και τα logs
πηγαίνουν στο stderr. Οι πρώτοι επτά clients ξεκινούν τον server μόνοι τους. Στα Windows, ένας
client που δεν μπορεί να ξεκινήσει απευθείας το `npx` χρειάζεται τη μορφή `cmd /c npx`, την οποία
τυπώνει το `config` όταν εκτελείται σε Windows (ή με `--platform win32`). Το `--profile` μεταβιβάζει
ένα [προφίλ εργαλείων](#tool-profiles) στον server.

### <a id="remote-clients-and-tunnels"></a>Απομακρυσμένοι clients και tunnels

Το ChatGPT και το OpenAI API δεν μπορούν να ξεκινήσουν ένα πρόγραμμα στον υπολογιστή σας. Φτάνουν
τον server σε μια δημόσια διεύθυνση HTTPS, οπότε τον εκτελείτε μέσω HTTP και βάζετε ένα tunnel
μπροστά του. Έτσι, ένας server που μπορεί να ελέγχει το TradingView όπου είστε συνδεδεμένοι βρίσκεται
στο διαδίκτυο: χρησιμοποιήστε `--profile readonly`, ένα ισχυρό token (`TV_MCP_AUTH_TOKEN`), τον
δημόσιο host του tunnel στο `--allowed-hosts` (`TV_MCP_ALLOWED_HOSTS`), και `--no-dashboard`, ώστε
τα αρχεία του dashboard να μη σερβίρονται μέσω του tunnel. Οι οδηγοί για το
[ChatGPT](../clients/chatgpt.md) και το [OpenAI API](../clients/openai-api.md) περιγράφουν τη
διαδικασία βήμα προς βήμα, και το [SECURITY.md](../../SECURITY.md#tunnels-and-remote-clients) απαριθμεί
τι μπορεί να φτάσει ακόμη ένα token μόνο ανάγνωσης.

## <a id="quick-start-from-source"></a>Γρήγορη εκκίνηση από τον πηγαίο κώδικα

Για να εκτελέσετε ένα checkout αντί για το δημοσιευμένο πακέτο, χρειάζεστε το Node.js 24 για να
κάνετε build τον server (το `nvm use` διαβάζει το `.nvmrc`) και το [pnpm](https://pnpm.io), του
οποίου την έκδοση καθορίζει το `package.json`. Ο server μετά το build τρέχει σε Node.js 20.19 ή
νεότερο.

```sh
git clone https://github.com/Mochamad-Rizky/tradingview-desktop-mcp.git
cd tradingview-desktop-mcp
pnpm install && pnpm build
node packages/server/dist/cli.js launch
node packages/server/dist/cli.js doctor
```

Το `node packages/server/dist/cli.js config <client> --local` τυπώνει το απόσπασμα ενός client για
αυτό το checkout, με το `node` και την απόλυτη διαδρομή του `cli.js` στη θέση του `npx`. Για έναν
client με ρύθμιση σε JSON, η καταχώριση μοιάζει έτσι:

```json
{
  "mcpServers": {
    "tradingview": {
      "command": "node",
      "args": ["/absolute/path/to/tradingview-desktop-mcp/packages/server/dist/cli.js"]
    }
  }
}
```

Υπάρχει επίσης transport HTTP (`--transport http`)· διαβάστε το [SECURITY.md](../../SECURITY.md) πριν το
χρησιμοποιήσετε.

## <a id="use-it"></a>Χρήση

Συνδέστε έναν MCP client όπως περιγράφεται παραπάνω, με το TradingView να τρέχει με τη θύρα
αποσφαλμάτωσης, και ζητήστε ό,τι θέλετε με απλά λόγια. Ο βοηθός επιλέγει τα εργαλεία και τα καλεί,
οπότε δεν χρειάζεται να ξέρετε τα ονόματά τους. Η [αναφορά εργαλείων](../tools.md) απαριθμεί κάθε
εργαλείο με τις παραμέτρους του και τα προφίλ στα οποία ανήκει.

### <a id="try-these-prompts"></a>Δοκιμάστε αυτά τα prompts

Κάθε prompt παρακάτω είναι ένα από τα παραδείγματα του [docs/examples.md](../examples.md), που
δείχνει τις κλήσεις εργαλείων που κάνει ο βοηθός και τα αποτελέσματα, με τις λίστες μεγαλύτερες από
τρία στοιχεία περικομμένες, τη διάρκεια κάθε κλήσης (`durationMs`) παραλειπόμενη και ένα στιγμιότυπο
οθόνης αναφερόμενο σε σημείωση αντί να εμφανίζεται. Τα αποσπάσματα είναι γραμμές από αυτά τα
αποτελέσματα, και το `…` σημειώνει πού παραλείπονται γραμμές από άλλα μέρη ενός αποτελέσματος. Οι
τιμές είναι συνθετικές: προέρχονται από μια ψεύτικη εφαρμογή TradingView με ένα επινοημένο γράφημα
NASDAQ:AAPL, οπότε τίποτα δεν είναι δεδομένα αγοράς και τίποτα δεν προέρχεται από κάποιον
λογαριασμό· τα αποτελέσματα έχουν τη μορφή που τους δίνει ο server, αν και η αναφορά του Strategy
Tester πίσω από το παράδειγμα του backtest δεν έχει διαβαστεί ακόμη από την πραγματική εφαρμογή.

**«Τι βλέπω στο γράφημά μου; Πες μου το σύμβολο, το χρονικό διάστημα και ποιοι δείκτες υπάρχουν
πάνω του.»** Ο βοηθός διαβάζει το γράφημα με το `chart_get_state`
([λεπτομέρειες](../examples.md#1-read-the-chart)):

```json
"symbol": "NASDAQ:AAPL",
"resolution": "1D",
"chartTypeName": "candles",
```

**«Δείξε μου τα τελευταία 3 ημερήσια κεριά.»** Διαβάζει τις μπάρες με το `data_get_ohlcv`
([λεπτομέρειες](../examples.md#3-read-the-last-candles)):

```json
"timeIso": "2024-10-27T00:00:00Z",
"open": 103.58,
"close": 103.42,
```

**«Πρόσθεσε τον MACD στο γράφημά μου.»** Σε ένα γράφημα που έχει ήδη όσους δείκτες επιτρέπει το
πλάνο, το `indicator_add` δεν προσθέτει τίποτα και αναφέρει το όριο, και η αφαίρεση ενός από τους
δείκτες σας για να ελευθερωθεί χώρος απαιτεί την επιβεβαίωσή σας
([λεπτομέρειες](../examples.md#5-add-an-indicator-to-a-full-chart)):

```json
"code": "PLAN_LIMIT",
"message": "The chart holds as many indicators as the plan allows (2)",
```

**«Γράψε έναν δείκτη Pine Script που σχεδιάζει έναν κινητό μέσο όρο 9 και έναν 21 μπαρών του
κλεισίματος, και έλεγξε ότι μεταγλωττίζεται.»** Βάζει το script στον Pine Editor με το `pine_new`
και το μεταγλωττίζει με το `pine_compile`
([λεπτομέρειες](../examples.md#6-write-and-compile-a-pine-script)):

```json
"success": true,
"errors": [],
"warnings": [],
```

**«Το script στον Pine Editor μου δεν μεταγλωττίζεται. Μπορείς να το διορθώσεις;»** Το
`pine_smart_compile` μεταγλωττίζει το script, εφαρμόζει διορθώσεις βάσει κανόνων για τα σφάλματα
που γνωρίζει, όπως ονόματα του Pine v4 σε script v6, και το μεταγλωττίζει ξανά, χωρίς να αλλάξει
τον editor ([λεπτομέρειες](../examples.md#7-fix-a-pine-script-with-smart-compile)):

```json
"message": "Could not find function or function reference 'study'",
…
"applied": ["Replace study( with indicator(", "Replace rsi( with ta.rsi("]
…
"writtenBack": false
```

**«Πώς τα πήγε η στρατηγική στο γράφημά μου στο backtest;»** Διαβάζει το Strategy Tester με το
`strategy_get_results` και το `strategy_get_trades`
([λεπτομέρειες](../examples.md#8-read-backtest-results)):

```json
"netProfit": 155,
"totalTrades": 3,
"percentProfitable": 66.67,
"profitFactor": 4.1,
```

**«Σχεδίασε μια γραμμή στήριξης στο 102.80 στο γράφημά μου.»** Σχεδιάζει μια οριζόντια γραμμή με το
`drawing_create`, και το `drawing_list` τη δείχνει δίπλα στα δικά σας σχέδια, σημειωμένη ως
σχεδιασμένη από αυτή τη συνεδρία ([λεπτομέρειες](../examples.md#9-draw-a-support-line)):

```json
"id": "DRW001",
"shape": "horizontal_line",
"text": "Support",
"createdByServer": true
```

**«Ειδοποίησέ με όταν η Apple περάσει το 110.»** Το `alert_create` ορίζει μια ειδοποίηση τιμής στον
λογαριασμό σας στο TradingView ([λεπτομέρειες](../examples.md#10-create-a-price-alert)). Όταν το
πλάνο έχει ήδη όσες ειδοποιήσεις επιτρέπει, δεν δημιουργεί τίποτα και αναφέρει το όριο, και το
`alert_list` δείχνει τις ειδοποιήσεις που το γεμίζουν
([λεπτομέρειες](../examples.md#11-create-an-alert-when-the-plan-is-full)):

```json
"symbol": "NASDAQ:AAPL",
"condition": "crossing",
"price": 110,
"expirationIso": "2024-11-26T00:00:00Z"
```

**«Πρόσθεσε αυτά τα σύμβολα στη λίστα παρακολούθησής μου: NYSE:IBM, FX:EURUSD, NASDAQ:MSFT και
NASDAQ:MSTF.»** Το `watchlist_add_bulk` ελέγχει κάθε σύμβολο με την αναζήτηση συμβόλων του
TradingView, προσθέτει τα νέα και εξηγεί γιατί παρέλειψε τα υπόλοιπα
([λεπτομέρειες](../examples.md#12-add-symbols-to-a-watchlist)):

```json
"added": ["NYSE:IBM", "FX:EURUSD"],
…
{ "symbol": "NASDAQ:MSFT", "reason": "already_listed" },
{ "symbol": "NASDAQ:MSTF", "reason": "unknown" }
```

**«Θέλω να εξασκηθώ σε bar replay του γραφήματός μου από τις 2024-06-03: προχώρα πέντε μπάρες
μπροστά, πες μου πού βρισκόμαστε και μετά τερμάτισε το replay.»** Ξεκινά το bar replay με το
`replay_start`, προχωρά με το `replay_step`, διαβάζει πού βρίσκεται το replay με το `replay_status`
και βγαίνει από αυτό με το `replay_stop`. Δεν γίνεται καμία συναλλαγή: κανένα εργαλείο δεν τοποθετεί
εντολές ([λεπτομέρειες](../examples.md#13-practice-with-bar-replay)):

```json
"dateIso": "2024-06-07T00:00:00Z",
"stepped": 5,
…
"position": null,
"realizedPL": null
```

**«Τράβηξε ένα στιγμιότυπο οθόνης του γραφήματός μου.»** Το `screenshot_capture` δίνει την εικόνα
στον βοηθό ως εικόνα, μαζί με το μέγεθός της, και δεν γράφει τίποτα στον δίσκο
([λεπτομέρειες](../examples.md#14-take-a-screenshot)):

```json
"data": { "target": "chart", "format": "jpeg", "width": 1180, "height": 640, "bytes": 3100 },
"meta": { "via": "cdp", "warnings": [] }
```

Ο server προσφέρει επίσης πέντε δικά του prompts, τα οποία ένας client που υποστηρίζει MCP prompts
σας εμφανίζει για να διαλέξετε: `analyze_current_chart`, `multi_timeframe_review`,
`write_and_backtest_strategy`, `debug_pine_script` και `replay_practice_session`. Το καθένα λέει
στον βοηθό ποια εργαλεία να καλέσει, με ποια σειρά, και τι να αναφέρει. Το `replay_practice_session`
εκτελεί μια συνεδρία εξάσκησης σε bar replay: ο βοηθός προχωρά στο παρελθόν μπάρα προς μπάρα, σας
ρωτά σε κάθε βήμα αν θα παίρνατε long, short ή θα μένατε εκτός αγοράς, κρατά ημερολόγιο αυτών των
υποθετικών συναλλαγών σε τιμές που διαβάζει από το γράφημα, και υπολογίζει το κέρδος ή τη ζημιά
τους. Ελέγχει πρώτα αν τρέχει κάποιο δικό σας replay, και σας ρωτά τι να κάνει με αυτό πριν αλλάξει
οτιδήποτε· στο τέλος σταματά το replay που ξεκίνησε ο ίδιος, και ποτέ κάποιο δικό σας.

### <a id="safety"></a>Ασφάλεια

Τα εργαλεία που αλλάζουν το γράφημα, τα scripts ή τον λογαριασμό σας είναι προσεκτικά με ό,τι σας
ανήκει ήδη. Η αντικατάσταση μη αποθηκευμένου κειμένου στον Pine Editor (εκτός από μια μη
αποθηκευμένη αλλαγή που έκανε εκεί η ίδια αυτή η συνεδρία του server), η αποθήκευση νέας έκδοσης
ενός script που δεν δημιούργησε αυτή η συνεδρία, και η αφαίρεση ενός δείκτη που υπήρχε ήδη στο
γράφημά σας απαιτούν όλα `confirm: true`, το οποίο ο βοηθός πρέπει να περνά μόνο αφού συμφωνήσετε.
Το ίδιο ισχύει για την αφαίρεση ενός σχεδίου, μιας ειδοποίησης, ενός συμβόλου λίστας παρακολούθησης
ή μιας καρτέλας που δεν δημιούργησε, δεν πρόσθεσε ή δεν άνοιξε αυτή η συνεδρία, για την αφαίρεση
όλων των σχεδίων ενός γραφήματος, για τη μετάβαση από μια διάταξη με μη αποθηκευμένες αλλαγές, και
για την αλλαγή σε διάταξη πολλαπλών γραφημάτων με λιγότερα γραφήματα από όσα δείχνει η καρτέλα, της
οποίας η επόμενη αποθήκευση θα έχανε τα υπόλοιπα. Ένα όριο πλάνου, όπως ο αριθμός των δεικτών σε
ένα γράφημα, των αποθηκευμένων scripts, των ειδοποιήσεων ή των γραφημάτων μιας διάταξης, ελέγχεται
πριν προστεθεί οτιδήποτε και αναφέρεται ως σφάλμα `PLAN_LIMIT` μαζί με το όριο· όταν το όριο δεν
μπορεί να διαβαστεί στην έκδοση του TradingView που έχετε, το εργαλείο δεν κάνει τίποτα και το
αναφέρει. Ο server δεν παρακάμπτει κανένα όριο. Τα εργαλεία ελέγχουν πρώτα τι θα έκανε το
TradingView να ανοίξει τον διάλογο αναβάθμισης ή κάποιον άλλο δικό του διάλογο, και αρνούνται
αντί γι' αυτό, αλλά απομένουν μερικά παράθυρα που αυτοί οι έλεγχοι δεν μπορούν να προβλέψουν:
το `layout_switch` μπορεί να συναντήσει προτροπή αναβάθμισης για μια αποθηκευμένη διάταξη πολλαπλών
γραφημάτων σε πλάνο με λιγότερα γραφήματα, για μια διάταξη που ο server του TradingView απορρίπτει
ως εκτός ορίου, και για μια διάταξη που η λίστα την οποία κρατά το TradingView για τον εαυτό του
σημειώνει ως πάνω από το όριο ενώ το `layout_list` όχι· το `layout_new` μπορεί να συναντήσει μήνυμα
του TradingView όταν αυτό απορρίπτει τη νέα διάταξη μετά τους ελέγχους· και το `tab_close` μπορεί
να συναντήσει τον διάλογο «Close tab?» για μια σελίδα που αργεί περισσότερο απ' όσο περιμένει το
TradingView να πει αν η διάταξή της έχει μη αποθηκευμένες αλλαγές, ή που αναφέρει εγγραφή σε
εξέλιξη. Τα εργαλεία χαμηλού επιπέδου `ui_*` κάνουν κλικ και πληκτρολογούν ό,τι τους ζητήσετε,
οπότε μπορούν από τη φύση τους να ανοίξουν διαλόγους του TradingView. Ο server δεν διαγράφει και
δεν μετονομάζει κανένα script.

Κανένα εργαλείο δεν τοποθετεί εντολές: το bar replay είναι για εξάσκηση, και ο βοηθός κρατά τις
συναλλαγές εξάσκησης μέσα στη συνομιλία. Τα στιγμιότυπα οθόνης πηγαίνουν στον client ως εικόνες, και
ο server δεν γράφει κανένα στον δίσκο. Το `ui_evaluate`, που εκτελεί JavaScript στη σελίδα του
γραφήματος, είναι απενεργοποιημένο εκτός αν ξεκινήσετε τον server με `--allow-eval`
(`TV_MCP_ALLOW_EVAL=true`).

### <a id="tool-profiles"></a>Προφίλ εργαλείων

Από προεπιλογή ο server προσφέρει και τα 83 εργαλεία του (`--profile full`). Ορισμένοι clients
δέχονται μόνο περιορισμένο αριθμό εργαλείων (το Cursor προειδοποιεί πάνω από 40). Για αυτούς, το
`--profile core` προσφέρει ένα μειωμένο σύνολο 40 βασικών εργαλείων, και το `--profile readonly`
προσφέρει μόνο τα 37 εργαλεία που διαβάζουν. Το `--tools` δέχεται μοτίβα ονομάτων όπως
`chart_*,data_*` και περιορίζει περαιτέρω το προφίλ: ένα εργαλείο πρέπει να ανήκει στο προφίλ και να
ταιριάζει με ένα μοτίβο, οπότε το `--profile core --tools 'pine_*'` εξακολουθεί να παραλείπει τα
`pine_open` και `pine_save`, που δεν είναι βασικά εργαλεία· με το προεπιλεγμένο προφίλ, το `--tools`
μόνο του επιλέγει τα εργαλεία. Ορισμένες περιγραφές και υποδείξεις αναφέρουν εργαλεία που το `core`
παραλείπει, όπως τα `pine_open` και `pine_save`, τα οποία ο βοηθός δεν μπορεί να καλέσει με το
`core`. Οι πόροι ακολουθούν τα εργαλεία: ο καθένας προσφέρεται μόνο μαζί με το εργαλείο με το οποίο
μοιράζεται τα δεδομένα του, όπως το `tradingview://pine/source` με το `pine_get_source`, οπότε το
`--tools 'chart_*'` προσφέρει την κατάσταση του γραφήματος και τίποτα από τον Pine Editor.

Η [αναφορά εργαλείων](../tools.md) απαριθμεί κάθε εργαλείο με τις παραμέτρους του και τα προφίλ
στα οποία ανήκει.

## <a id="dashboard"></a>Dashboard

Ο server συνοδεύεται από ένα web dashboard για να παρακολουθείτε τι κάνει ο βοηθός σας και για να
δοκιμάζετε ένα εργαλείο χειροκίνητα. Δεν χρειάζεται επιπλέον εγκατάσταση: το δημοσιευμένο πακέτο το
περιέχει, και το `pnpm build` το ενσωματώνει στον server ενός checkout.

![Η σελίδα κατάστασης: το TradingView είναι προσβάσιμο, με γράφημα που εντοπίστηκε και την εφαρμογή έτοιμη, τα στοιχεία του server και τα όρια του πλάνου](../images/dashboard-status.png)

### <a id="open-it"></a>Άνοιγμα

- **Transport HTTP:** ξεκινήστε τον server με ένα token και ανοίξτε το `http://127.0.0.1:8787/`. Το
  dashboard είναι ενεργό από προεπιλογή σε αυτή τη λειτουργία· το `--no-dashboard`
  (`TV_MCP_DASHBOARD=false`) το απενεργοποιεί.

  ```sh
  TV_MCP_AUTH_TOKEN="$(openssl rand -hex 32)" npx -y tradingview-desktop-mcp --transport http
  ```

  Από ένα checkout, εκτελέστε αντί γι' αυτό `node packages/server/dist/cli.js --transport http`.

- **Παράλληλα με το stdio:** ένας MCP client που ξεκινά τον server μέσω stdio μπορεί επίσης να έχει
  dashboard. Προσθέστε το `--dashboard` (`TV_MCP_DASHBOARD=true`) και το `TV_MCP_AUTH_TOKEN` στη
  ρύθμισή του. Το dashboard ακούει στη δική του διεύθυνση, `127.0.0.1:8787` εκτός αν ορίσετε
  `--host` και `--port`, και δεν σερβίρει `/mcp`. Χωρίς το token, ή όταν η θύρα είναι κατειλημμένη,
  το dashboard μένει ανενεργό και ο server καταγράφει μια προειδοποίηση, αλλά ο MCP server συνεχίζει
  να τρέχει. Οι κλήσεις που κάνει ο client εμφανίζονται στο ζωντανό log.

Ο server τυπώνει τη διεύθυνση του dashboard στο stderr όταν ξεκινά. Δεν τυπώνει ποτέ το token.

### <a id="the-token"></a>Το token

Η σελίδα ζητά το token (`TV_MCP_AUTH_TOKEN`) πριν δείξει οτιδήποτε. Επικολλήστε το, ή ανοίξτε μία
φορά το `http://127.0.0.1:8787/#token=<token>`: η σελίδα διαβάζει το token από το fragment και το
αφαιρεί από τη διεύθυνση, και το fragment δεν αποστέλλεται ποτέ στον server. Η σελίδα κρατά το
token στο `sessionStorage`, οπότε χάνεται όταν κλείσετε την καρτέλα, και το στέλνει μόνο ως
`Authorization: Bearer <token>`, ποτέ μέσα σε URL. Όταν ο server επανεκκινηθεί με άλλο token, η
σελίδα το ζητά ξανά. Δείτε το [SECURITY.md](../../SECURITY.md#the-dashboard).

### <a id="what-it-shows"></a>Τι δείχνει

![Το ζωντανό log: ένας πίνακας με κλήσεις εργαλείων, τις νεότερες πρώτες, με τον χρόνο, το εργαλείο, την προέλευση, την κατάσταση και τη διάρκειά τους, και από πάνω η αναζήτηση και τα φίλτρα](../images/dashboard-log.png)

- Το **Status** δείχνει αν το TradingView είναι προσβάσιμο (και πώς να το ξεκινήσετε όταν δεν
  είναι), πώς τρέχει ο server, τα όρια του πλάνου και τις πιο πρόσφατες κλήσεις.
- Το **Log** μεταδίδει ζωντανά κάθε κλήση εργαλείου που εκτελεί ο server, είτε την έκανε ένας MCP
  client είτε το dashboard, με φίλτρο ανά όνομα εργαλείου, παύση, καθαρισμό και τις λεπτομέρειες
  κάθε κλήσης. Μετά από διακοπή σύνδεσης δείχνει «Reconnecting…» και συνεχίζει από εκεί που
  σταμάτησε. Κάθε ανοιχτή καρτέλα του dashboard κρατά μία ροή γεγονότων προς τον server, και ένας
  browser επιτρέπει περίπου έξι συνδέσεις προς έναν host, οπότε με πολλές καρτέλες του dashboard
  ανοιχτές μια νέα μπορεί να περιμένει να ελευθερωθεί μια σύνδεση: κλείστε τις καρτέλες που δεν
  χρησιμοποιείτε.
- Το **Tools** απαριθμεί τα εργαλεία που προσφέρει ο server, με τις παραμέτρους τους, και εκτελεί
  ένα χειροκίνητα. Το αποτέλεσμα εμφανίζεται όπως επέστρεψε, με τα μεγάλα JSON συμπτυγμένα πίσω από
  το «Show all» και τις εικόνες ως εικόνες.

![Η σελίδα εργαλείων: η λίστα εργαλείων με την αναζήτηση και τα φίλτρα της αριστερά, και το chart_get_state με την περιγραφή, τα στοιχεία και τα πεδία παραμέτρων του δεξιά](../images/dashboard-tools.png)

Μια εκτέλεση από το dashboard είναι πραγματική κλήση εργαλείου. Περνά από το ίδιο registry με μια
κλήση MCP, οπότε ισχύουν τα ίδια schemas, το ίδιο προφίλ, οι κανόνες `confirm` και οι έλεγχοι ορίων
πλάνου, και εμφανίζεται στο log. Το dashboard σας ζητά επιβεβαίωση πριν εκτελέσει οποιοδήποτε
εργαλείο που δεν είναι μόνο ανάγνωσης.

### <a id="the-api"></a>Το API

Η σελίδα επικοινωνεί με τον server μέσω ενός μικρού API, το οποίο μπορείτε επίσης να καλέσετε με
`curl` και το token. Κάθε route απαιτεί `Authorization: Bearer <token>`, και ο server ελέγχει τα
`Host` και `Origin` όπως κάνει για το `/mcp`.

| Route                    | Τι κάνει                                                                           |
| ------------------------ | ---------------------------------------------------------------------------------- |
| `GET /api/info`          | Έκδοση, transport, προφίλ, πλήθος εργαλείων και ώρα εκκίνησης                      |
| `GET /api/health`        | Η αναφορά υγείας: αν το TradingView είναι προσβάσιμο                               |
| `GET /api/tools`         | Τα διαθέσιμα εργαλεία, με τα schemas και τα annotations τους                       |
| `POST /api/tools/<name>` | Εκτελεί ένα εργαλείο με `{"arguments": {...}}`, με προέλευση `dashboard`           |
| `GET /api/events`        | Server-sent events των κλήσεων εργαλείων· το `?limit=` ορίζει πόσα θα αναπαραχθούν |

Τα αρχεία της ίδιας της σελίδας, στο `/`, δεν χρειάζονται token και δεν περιέχουν δεδομένα.
